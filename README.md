Это проект игры дополненной реальности созданый для мехбота Ellic.
Игра проводится на физической площадке школьного спортзала (20x40м).
Игрок физически встаёт в кабину мехбота Ellic и потом одевает vr очки в режиме дополненной реальности.
Игрок использует мехбота Ellic для физического перемещения по площадке и стрельбы по виртуальному противнику.
В игре есть виртуальный противник убегающий, догоняющий и стреляющий в пилота на мехботе Ellic.
