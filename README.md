Это проект игры дополненной реальности созданый для мехбота Ellic.

Игра проводится на физической площадке школьного спортзала (20x40м).

Игрок физически встаёт в кабину мехбота Ellic и потом одевает vr очки в режиме дополненной реальности.

Игрок использует мехбота Ellic для физического перемещения по площадке и стрельбы по виртуальному противнику.

В игре есть виртуальный противник убегающий, догоняющий и стреляющий в пилота на мехботе Ellic.

Для начала работы скачайте проект через вкладку code в формате zip.

После этого распакуйте его через любой разархиватор.

Потом перейдите в распакованную папку ELLIC и потом перейдите в папку MyProject3

Для того чтобы открыть проект запустите MyProject3.uproject через UnrealEngine версии 5.3.

Проект можно свободно редактировать для своих целей.

Для установки игры на pico 4 перейдите по пути MyProject3 Android_ASTC.

И траспортируйте apk файл на шлем, запустите файл на шлеме, и потом запустите игру.
